Why work with me

Most freelance testers can click through a UI. Fewer can also build the automation framework behind it, validate what's actually stored in the database, and put a real device in their hand to check it. That combination is what I bring to every engagement.

  • I build automation frameworks from scratch — Selenium, Appium, Python & Pytest — rather than just running someone else's scripts, so your suite is yours to keep and extend.
  • I check the data, not just the screen: API validation with Postman and backend verification in MongoDB/SQL, so bugs hiding behind the UI don't slip through.
  • I've tested on real hardware, not just simulators — Android VoIP/telecom devices, firmware regression, call workflows and caption accuracy for accessibility users.
  • I write test plans and defect reports clients can actually act on, tracked in JIRA/Xray, with clean handoff at the end of every sprint.

    What You Actually Get

    Every engagement comes with documentation like this — traceable test cases, priority/severity, and clear pass/fail evidence, not a vague "looks fine to me."

    TC ID Module Steps Expected Result Priority Status
    TC-047 Camera — Autofocus Open camera app → point at subject → tap shutter Autofocus locks within 1s; captured image is sharp High Pass
    TC-048 Login — Invalid Password Enter valid email → enter wrong password → tap Login Shows "Incorrect password" toast; no crash Critical Pass
    TC-052 Checkout API POST /api/v1/checkout with an expired auth token Returns 401 Unauthorized; no 500 error Critical Fail — Sev-2 logged
    TC-061 Android — Rotation Start video recording → rotate device 90° Recording continues uninterrupted; layout re-flows correctly Medium Pass

    Sample format for illustration — every real engagement gets its own test cases mapped to your actual PRD/requirements.
